Open source system monitor and photo album software base on Python  
> Modified from https://github.com/WeActStudio/WeActStudio.SystemMonitor

## Support Hardware
* **WADFS-35(3.5Inch)**  
Resolution: 320 x 480 RGB565  
Communication Mode: USB2.0 FS (CDC)  
Sensor: Humidity + Temperature  
Size: 58.5mm x 87.7mm 

> You can by https://bit-trade-one.co.jp/wadfs35/

## Special for this repository
1. You can display the HP of monsters from the Steam version of Monster Hunter.
2. The previous function of displaying PC usage and GPU usage has been retained.
3. The use of a MOD is required. We are not responsible for data loss caused by the use of a MOD.
4. Please refer to this note for detailed instructions.
